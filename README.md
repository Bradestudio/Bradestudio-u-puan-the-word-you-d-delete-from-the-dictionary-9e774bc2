# The Word You'd Delete From the Dictionary

A [make.fun](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) entry: the single word to erase from the dictionary forever.

## The entry

> Moist

It is the word people most love to hate — not for what it means, but for how it sounds crawling out of your mouth. Say it and a whole room winces. Delete it and nobody would miss it; everybody would feel relieved.

## Run

```sh
python3 main.py
```

The program writes that single word to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). It checks the word first: 1–77 characters, not blank, exactly one token.

`main.py` is standard library only, makes no network calls, and reads no files.
